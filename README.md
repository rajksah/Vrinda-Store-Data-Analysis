# Vrinda Store Data Analysis

## 📌 Project Overview

This project focuses on analyzing Vrinda Store sales data using Microsoft Excel to identify sales trends, customer behavior, order patterns, and key business insights.

The analysis was performed using data cleaning, Excel formulas, pivot tables, charts, and data visualization techniques.

## 🎯 Objective

The main objective of this project is to analyze store sales data and identify:

- Overall sales performance
- Monthly sales trends
- Customer purchasing patterns
- Sales by gender and age group
- Top-performing product categories
- Order status and delivery performance
- Sales contribution across different channels
- Key business insights for improving sales
